# A Comparative Analysis of Classification Models for Predicting FIFA World Cup Outcomes Using Pre-Match Statistics

**Phenyo Nelwamondo – ST10260322**
RPDA8412 Research Project, Postgraduate Diploma in Data Analytics, The Independent Institute of Education

## Contents
- `FIFA_WorldCup_Analysis.ipynb` – full analysis: data preparation, feature engineering, model training (Logistic Regression, Random Forest, SVM, XGBoost), evaluation, statistical testing and robustness check
- `matches_1930_2022.csv` – FIFA World Cup match data
- `fifa_ranking-2024-06-20.csv` – historical FIFA rankings

## Data sources
- Ivaniuk, P. (2026). *Football – FIFA World Cup, 1930–2026*. Kaggle: https://www.kaggle.com/datasets/piterfm/fifa-football-world-cup
- Alex (2024). *FIFA World Ranking 1992–2024*. Kaggle: https://www.kaggle.com/datasets/cashncarry/fifaworldranking

## How to run
Keep both CSV files in the same folder as the notebook and run all cells in Jupyter Notebook.
Libraries: pandas, numpy, scikit-learn, xgboost, scipy, statsmodels, matplotlib.
